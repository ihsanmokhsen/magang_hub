# BPAD Magang Hub

Web statis onboarding peserta magang BPAD Provinsi NTT yang di-host di Netlify.

## Fitur yang tersedia
- Landing page dengan tombol **Mulai**.
- Halaman utama berisi pengantar, ringkasan BPAD, aturan magang, dokumen penting, dan game singkatan.
- Tautan **Laporan Harian** ke Tally: https://tally.so/r/682JGe
- Progress baca dokumen dan checklist hari pertama tersimpan di `localStorage`.
